# Discord 非對稱派對遊戲：企劃與可行性評估

> 2026-11-18 建立。靈感來源：巴哈姆特 GNN 報導的《我帶過的最差一屆》（1 名老師 vs 最多 7 名學生，學生混在 NPC 裡搗蛋、老師找出真人）。
> **我們做的是同類型的原創遊戲，不是復刻它**：不用它的名稱、角色、美術、關卡與道具設計。「躲在 NPC 群裡、一個人負責抓」這個玩法類型本身很常見（例如 Spy Party、Hidden in Plain Sight），可以自由發揮。

## 1. 結論：做得出來

Discord 的「活動 (Activities)」就是在語音頻道裡開一個網頁遊戲（Embedded App SDK，HTML5 跑在 iframe 裡），大家一起玩，手機和電腦都能進。這類「一抓多、躲在 NPC 裡」的玩法很適合：

| 需求 | Discord 活動能不能做 | 說明 |
|---|---|---|
| 2–8 人即時連線 | 可以 | 自己架 WebSocket 伺服器，同一個語音頻道的人自動進同一房 (`instanceId`) |
| 知道誰是誰 | 可以 | Discord OAuth 拿到使用者名稱、頭像，不用另外註冊 |
| 語音聊天 | 不用做 | 大家本來就在語音頻道裡 |
| 手機玩 | 可以 | 要設計觸控操作，畫面要能直式/橫式 |
| 3D 大場景 | 不建議 | iframe + 手機效能有限，**改做 2D 俯視角**（Canvas / Phaser / PixiJS）比較穩 |
| 幾十個 NPC 同步 | 可以 | NPC 由伺服器跑，只送位置，資料量很小 |

**最大的難點不是 Discord，而是遊戲設計**：NPC 的行為要夠像真人，玩家才躲得住；抓錯要有懲罰，不然老師會亂點。

## 2. 原創玩法草案（待討論，先暫名《自習室抓鬼》）

- **角色**：1 名「巡堂員」 vs 2–7 名「搗蛋鬼」，混在 20–40 個 NPC 學生裡。
- **場景**：2D 俯視角的教室／圖書館／社團教室，每張地圖有不同的「任務點」。
- **搗蛋鬼目標**：在時限內完成任務（例如在黑板偷畫一筆、把便當傳到最後一排、在窗邊比暗號），任務進行時會有明顯的小動作，巡堂員看得到。
- **巡堂員目標**：觀察誰的行為不像 NPC，點名抓人。抓錯 NPC 會扣時間或扣次數。
- **NPC**：會抄筆記、打瞌睡、轉頭聊天、起身丟垃圾——搗蛋鬼要模仿這些動作才不會露餡。
- **與原作區隔的點子**（擇一或混搭）：
  - 搗蛋鬼之間能用「暗號動作」互相認出，合作完成雙人任務。
  - 巡堂員有「回放 5 秒」技能，可以倒帶看剛剛誰動了。
  - 每局隨機「班規」（例如：這局不准站起來，NPC 也會遵守）。

## 3. 技術架構

```
Discord 語音頻道
  └─ 活動 iframe（前端：TypeScript + PixiJS/Phaser，2D）
        │  Embedded App SDK：拿 instanceId、使用者身份
        ▼  WebSocket（經 Discord URL Mapping 代理）
遊戲伺服器（Node.js，權威伺服器）
  ├─ 房間 = instanceId，跑 NPC AI、判定任務與抓人
  └─ 20 tick/s 廣播位置
```

- **前端**：Vite + TypeScript，2D 引擎用 PixiJS 或 Phaser。
- **後端**：Node.js + `ws`（或 Colyseus 房間框架）。所有判定在伺服器（防作弊：客戶端只送操作）。
- **身份**：Discord OAuth2 授權碼 → 伺服器換 token → 拿使用者資料。
- **部署**：Discord 規定活動網址必須是 HTTPS，並在 Developer Portal 設 URL Mapping。
  - 可以先放在現有的 GCP VM（e2-micro，免費方案），但 RAM 只有 1 GB，同時跟 LifeHub 一起跑，只適合小規模測試。
  - 人多時再換 Cloud Run 或更大的 VM（會開始收費，要先估價）。

## 4. 開發階段（建議順序）

1. **原型（1–2 週）**：本機網頁版，一張地圖、NPC 會走動、1 人抓 + 1 人躲，先驗證「好不好玩」。
2. **多人連線**：WebSocket 房間、8 人同步、計分。
3. **接 Discord**：建立 Discord Application、Embedded App SDK、OAuth、URL Mapping，在自己的伺服器測試。
4. **內容**：3 張地圖、任務種類、班規、手機操作。
5. **上架**：Discord 活動要公開給所有伺服器用，需要通過 Discord 的審核；只在自己的伺服器玩則不用。
