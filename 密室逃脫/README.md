# 隔代房間（密室逃脫）

你們被困在同一個地方的兩個年代：**1990** 和 **2030**。
1990 做的每件事都會留到未來——搬東西、藏東西、種樹、漏水把地板泡爛。
兩邊靠語音（Discord）互相傳話，一起把 2030 的出口打開。

## 怎麼玩

1. 下載 [`隔代房間.html`](隔代房間.html)，點兩下用 Chrome 或 Edge 打開（要有網路，3D 引擎從網路載入）。
2. 一個人：選「單機試玩」，按 **Tab** 切換 1990 / 2030。
3. 多人：房主按「開房」→ 產生邀請碼貼給朋友 → 朋友貼回回覆碼 → 房主按連線 → 開始。不需要伺服器。

| 按鍵 | 功能 |
|---|---|
| WASD | 走路 |
| 滑鼠 | 轉頭（先點一下畫面） |
| E | 拿起／放下／互動 |
| H | 提示（次數看難度） |
| Tab | 單機時切換年代 |

**手機**：用手機打開會自動切換成觸控模式（要橫拿）。左半邊按住拖曳走路、右半邊滑動轉頭、右下大按鈕互動，右上有提示和線索按鈕。主選單的「操作」按鈕可以手動切換。

## 關卡

| 關卡 | 玩法 |
|---|---|
| 第一關・阿嬤的客廳 | 教學：生長、封存、傳話 |
| 第二關・理化教室 | 反向查證、封存、固定 |
| 第三關・巷口雜貨店 | 侵蝕、自助付款、雙向密碼 |
| 第四關・海邊燈塔 | 光線、時鐘、兩邊同時拉桿 |
| 第五關・老照相館 | 雙向密碼、保存環境、翻拍底片 |
| 第六關・港邊老倉庫 | 位置被打亂要做記號、埋進水泥、上油防鏽 |

難度分簡單／普通／困難（提示次數、時間裂痕上限、拉桿秒數不同）。過了前一關才會解鎖下一關。
可以捏角色；不同年代的隊友會看到你半透明的「時間殘影」。
