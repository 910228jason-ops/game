# 隔代房間（密室逃脫）

你們被困在同一個地方的兩個年代：**1990** 和 **2030**。
1990 做的每件事都會留到未來——搬東西、藏東西、種樹、漏水把地板泡爛。
兩邊靠語音（Discord）互相傳話，一起把 2030 的出口打開。

## 怎麼玩

1. 直接打開 https://910228jason-ops.github.io/game/ （電腦、手機都可以；也可以下載 [`隔代房間.html`](隔代房間.html) 用 Chrome 或 Edge 打開，要有網路）。
2. 一個人：選「單機試玩」，按 **Tab** 切換 1990 / 2030。
3. 多人（大家先進同一個 Discord 語音頻道）：
   1. 房主按「開房」，畫面上會出現 4 個字的**房間碼**。按「複製邀請連結」貼到 Discord。
   2. 朋友點連結，或按「加入朋友的房間」輸入房間碼，再按「加入」。
   3. 人到齊、1990 和 2030 都有人之後，房主按「開始遊戲」。
   - 房間碼只用來配對（透過 PeerJS 免費的公開配對服務）；連上之後，遊戲資料是玩家之間直接傳。
   - 配對服務連不上時，展開「連不上？改用連線碼（舊方法）」：房主產生邀請碼貼給朋友 → 朋友貼回回覆碼 → 房主按連線。

| 按鍵 | 功能 |
|---|---|
| WASD | 走路 |
| 滑鼠 | 轉頭（先點一下畫面） |
| E | 拿起／放下／互動 |
| H | 提示（次數看難度） |
| Tab | 單機時切換年代 |

**手機**：用手機打開會自動切換成觸控模式（要橫拿）。左半邊按住拖曳走路、右半邊滑動轉頭、右下大按鈕互動，右上有提示和線索按鈕。主選單的「操作」按鈕可以手動切換。

## 關卡

遊戲分成好幾章，每一章是一種不同的密室，配色和畫風也不一樣；同一章的幾關共用主題和核心機關。
**每一章都可以直接玩**，但章內要從第一關開始，過了才解鎖下一關。★ 越多越難。

**第一章・隔代房間（1990 × 2030）**：同一個房間的兩個年代，1990 做的事會留到未來。

| 關卡 | 玩法 |
|---|---|
| 第一關・阿嬤的客廳 ★ | 教學：生長、封存、傳話 |
| 第二關・理化教室 ★ | 反向查證、封存、固定 |
| 第三關・巷口雜貨店 ★★ | 侵蝕、自助付款、雙向密碼 |
| 第四關・海邊燈塔 ★★★ | 光線、時鐘、兩邊同時拉桿 |
| 第五關・老照相館 ★★★ | 雙向密碼、保存環境、翻拍底片 |
| 第六關・港邊老倉庫 ★★★★ | 位置被打亂要做記號、埋進水泥、上油防鏽 |

**第二章・深海研究站（控制室 × 機房）**：兩個不同的房間。控制室看得到螢幕、負責指揮；機房看不到螢幕，負責動手。

| 關卡 | 玩法 |
|---|---|
| 第七關・緊急撤離 ★★ | 保險絲順序、閥門開關、符號換數字的艙門密碼（每局隨機） |
| 第八關・淹水的艙段 ★★★ | 抽水機會互相影響，要推理按哪幾台；氧氣倒數 |
| 第九關・聲納導航 ★★★★ | 控制室看地圖、機房只能左轉右轉前進；氧氣倒數 |
| 第十關・核心過熱 ★★★★★ | 冷卻棒換算＋兩邊同時排熱；章節最終關，倒數 |

**難度看的是要討論多少、解謎多深**，不是次數：三種難度都是提示 3 次、失誤上限 3 次。
- 簡單：線索比較直接、步驟比較少
- 普通：兩邊要交換資訊才解得開
- 困難：兩邊都只有一半的線索，要一起推理（例如密碼用代號、規則要用對方那邊才看得到的數字）
可以捏角色；不同年代的隊友會看到你半透明的「時間殘影」。
