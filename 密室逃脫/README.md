# 隔代房間（密室逃脫）

你們被困在同一個地方的兩個年代：**1990** 和 **2030**。
1990 做的每件事都會留到未來——搬東西、藏東西、種樹、漏水把地板泡爛。
兩邊靠語音（Discord）互相傳話，一起把 2030 的出口打開。

## 怎麼玩

1. 下載 [`隔代房間.html`](隔代房間.html)，點兩下用 Chrome 或 Edge 打開（要有網路，3D 引擎從網路載入）。
2. 一個人：選「單機試玩」，按 **Tab** 切換 1990 / 2030。
3. 多人：房主按「開房」→ 產生邀請碼貼給朋友 → 朋友貼回回覆碼 → 房主按連線 → 開始。不需要伺服器。

| 按鍵 | 功能 |
|---|---|
| WASD | 走路 |
| 滑鼠 | 轉頭（先點一下畫面） |
| E | 拿起／放下／互動 |
| H | 提示（次數看難度） |
| Tab | 單機時切換年代 |

**手機**：用手機打開會自動切換成觸控模式（要橫拿）。左半邊按住拖曳走路、右半邊滑動轉頭、右下大按鈕互動，右上有提示和線索按鈕。主選單的「操作」按鈕可以手動切換。

## 關卡

遊戲分成好幾章，每一章是一種不同的密室，配色和畫風也不一樣；**每章圍繞一條主線劇情**，每關揭開故事的一塊。
**每關有 3～5 個不同類型的謎題**，其中一定有「要先看懂條件才會觸發」的機關；每關還要找回一樣「回憶物件／證據」，出口才會打開。
**每一章都可以直接玩**，但章內要從第一關開始，過了才解鎖下一關。★ 越多越難。

**第一章・隔代房間：阿嬤留下的鑰匙（1990 × 2030）**：阿嬤過世後留下一把鑰匙，帶你們回到她一生去過的六個地方，找回六樣回憶。

| 關卡 | 玩法 |
|---|---|
| 第一關・阿嬤的客廳 ★ | 教學：生長、封存、傳話 |
| 第二關・理化教室 ★ | 反向查證、封存、固定 |
| 第三關・巷口雜貨店 ★★ | 侵蝕、自助付款、雙向密碼 |
| 第四關・海邊燈塔 ★★★ | 光線、時鐘、兩邊同時拉桿 |
| 第五關・老照相館 ★★★ | 雙向密碼、保存環境、翻拍底片 |
| 第六關・港邊老倉庫 ★★★★ | 位置被打亂要做記號、埋進水泥、上油防鏽 |

**第二章・深海研究站：深藍七號事故（控制室 × 機房）**：研究站進水，你們邊逃邊發現站長隱瞞了核心過熱，一路帶出三份證據。控制室看得到螢幕、負責指揮；機房負責動手。

| 關卡 | 玩法 |
|---|---|
| 第七關・緊急撤離 ★★ | 保險絲順序、閥門開關、符號換數字的艙門密碼（每局隨機） |
| 第八關・淹水的艙段 ★★★ | 抽水機會互相影響，要推理按哪幾台；氧氣倒數 |
| 第九關・聲納導航 ★★★★ | 控制室看地圖、機房只能左轉右轉前進；氧氣倒數 |
| 第十關・核心過熱 ★★★★★ | 冷卻棒換算＋兩邊同時排熱；章節最終關，倒數 |

**難度看的是要討論多少、解謎多深**，不是次數：三種難度都是提示 3 次、失誤上限 3 次。
- 簡單：線索比較直接、步驟比較少
- 普通：兩邊要交換資訊才解得開
- 困難：兩邊都只有一半的線索，要一起推理（例如密碼用代號、規則要用對方那邊才看得到的數字）
可以捏角色；不同年代的隊友會看到你半透明的「時間殘影」。

## 檔案

- `測試/自動測試.js`：自動把每關每種難度從頭玩到逃出（用法見 AI交接.md）
- `AI交接.md`：給接手的 AI 看的完整交接（架構、測試、上傳方式、待辦）
- `設計/設計稿/`：Design 設計稿原始檔
- `隔代房間.html`：遊戲本體（單一檔案，Three.js）
- `設計/關卡設計.md`：每一關的謎題鏈和規則
- `設計/企劃_隔代房間與耳語群島.md`：原始企劃
