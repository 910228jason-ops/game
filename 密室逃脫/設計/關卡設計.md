# 《隔代房間》密室逃脫關卡設計

> 2026-11-18。方向：**合作密室逃脫**。每一關都是一間鎖住的房間，1990 組和 2030 組各在同一個地點的不同年代，
> 必須互相傳話、交換物品（透過「時間」），一起把 2030 那邊的出口打開。

## 設計原則

1. **每道謎題都要兩個年代合作**：單靠一邊永遠解不開。
2. **資訊要雙向流動**：有的關卡是 1990 → 2030 傳答案，有的反過來 2030 → 1990（未來的人查得到過去的資料）。
3. **最重要的謎題要靠「動東西」**：只用嘴巴報密碼的謎題當暖身就好，因為語音一說就解了；真正的關卡要靠「1990 做了什麼，讓 2030 的世界變了」。
4. **做錯可以補救**：把重要物品丟掉會出現「時間裂痕」，東西會被「時間修正」放回原位；累積 3 道裂痕這關失敗。

## 時間規則（玩法工具箱）

| 規則 | 1990 做的事 | 2030 看到的結果 |
|---|---|---|
| 位置保留 | 搬動傢俱、物品 | 東西還在那個位置（積灰塵） |
| 封存 vs 腐化 | 東西放進密封鐵盒、密封櫃 | 保存完好；沒封存的會生鏽、乾掉、腐爛 |
| 生長 | 把樹苗種在曬得到太陽的地方 | 長成大樹，可以爬 |
| 固定 | 把講桌推到某個位置 | 後來那裡被裝成固定的實驗桌，搬不動 |
| 侵蝕 | 讓水一直滴在地板上（拿走水桶） | 地板腐爛出一個洞，可以往下走 |
| 刻痕 | 用圓規在桌子底下刻字 | 刻痕還在 |
| 做記號 | 用油漆在東西上做記號 | 東西被搬亂了，只認得記號 |
| 埋進水泥 | 把東西按進濕水泥 | 水泥裡封著它，要敲開 |
| 上油保養 | 給鐵器上油 | 不會鏽死，還能動 |
| 反向查證 | — | 2030 查得到舊資料（資產清冊、報紙），把答案報給 1990 |

## 地圖一：阿嬤的客廳（教學關，✅ 試玩版已做）

- **2030 出口**：大門上鎖。鑰匙卡在天花板的通風口裡，通風口用螺絲鎖住，而且太高搆不到。
- **謎題鏈**：
  1. **生長**：1990 把窗邊陰暗角落的小樹苗，搬到窗戶下曬得到太陽的地方 → 2030 長成大樹，可以爬上去碰到通風口。
  2. **封存**：1990 的工具箱裡有螺絲起子。要先把它放進餅乾鐵盒、再把鐵盒收進木櫃 → 2030 打開木櫃，拿到完好的螺絲起子。直接放進木櫃的話，2030 只會找到一團鏽。
  3. **傳話（1990 → 2030）**：2030 的木櫃被裝了密碼鎖，提示「阿嬤的生日」。1990 牆上的掛曆圈著那一天。
  4. 2030 拿螺絲起子、爬樹、打開通風口拿到鑰匙 → 開門逃出。
- **陷阱**：把樹苗或鐵盒丟進垃圾桶 → 時間裂痕。

## 地圖二：理化教室（✅ 試玩版已做）

- **2030 出口**：教室門的電子鎖斷電。唯一的路是講台下面的地下室活板門。
- **謎題鏈**：
  1. **傳話（2030 → 1990，反向）**：1990 的密封櫃是老師設的密碼，1990 不知道；2030 的櫃子上貼著資產清冊標籤，寫著原密碼。
  2. **封存**：1990 用密碼打開密封櫃，把架上的除鏽劑放進去 → 2030 拿到還能用的除鏽劑。放在架上的話，2030 只看到乾掉的空瓶。
  3. **固定**：1990 的講桌壓在活板門上；2030 那張實驗桌被鎖死在地上。1990 要先把講桌推到窗邊 → 2030 實驗桌就固定在窗邊，活板門露出來。
  4. 2030 用除鏽劑弄開生鏽的鎖頭 → 從活板門逃出。

## 地圖三：巷口雜貨店（✅ 試玩版已做）

- **主題**：1990 是熱鬧的柑仔店（老闆出去了，自助付款）；2030 是廢棄店面，鐵捲門鏽死。
- **2030 出口**：地板爛出的洞 → 樓下倉庫 → 後門。洞約 3 公尺深，要有繩子才下得去。
- **謎題鏈**：
  1. **雙向密碼**：1990 保險箱密碼不知道。2030 牆上裱框發票背面寫「密碼＝開幕那天（月月日日）」但日期糊掉；1990 牆上海報寫「7 月 25 日開張」→ 兩邊湊起來才知道 0725。
  2. **自助付款**：1990 從保險箱拿零錢，投進收銀機，才能從貨架拿麻繩。
  3. **封存**：麻繩放進時光膠囊、再把膠囊藏進櫃台後的地板暗格 → 2030 掀開暗格拿到完好的麻繩。直接塞進暗格的話，2030 只看到爛掉的繩子。
  4. **侵蝕**：1990 屋頂漏水，下面接著水桶。把水桶拿開（放到門邊）→ 2030 那塊地板爛出大洞。
  5. 2030 把麻繩綁好爬下洞 → 逃出。
- **陷阱**：把零錢、麻繩、膠囊、水桶丟進垃圾桶 → 時間裂痕。

## 地圖四：海邊燈塔（✅ 試玩版已做）

- **主題**：1990 燈塔值班室；2030 燈塔廢棄，只剩逃生梯能出去。
- **謎題鏈**：
  1. **光線（2030 指揮 1990）**：1990 可以轉動房間中間的反射鏡（左／中／右）。2030 看得到黃昏的光被反射到後牆哪裡；左邊那塊牆暗暗的好像刻著字。2030 用語音指揮 1990 轉到「左邊」，光照亮刻字：「守燈人每天 04:15 收工」。
  2. **時鐘（2030 → 1990）**：2030 老爺鐘的鐘箱鎖著，寫著「停在守燈人收工的時間才會打開」。1990 把老爺鐘撥到 04:15 並卡住鐘擺 → 2030 的鐘停在 04:15，鐘箱打開，拿到拉桿把手。
  3. **修好拉桿**：2030 的拉桿把手斷了，裝上把手。
  4. **兩邊同時**：逃生梯的門要 1990 和 2030 在 3 秒內一起拉下拉桿（單機試玩放寬到 8 秒）。用語音倒數「3、2、1、拉！」→ 逃出。

## 地圖五：老照相館（✅ 試玩版已做）

- **主題**：1990 照相館，老闆在暗房沖照片；2030 廢棄，只剩暗房門（密碼鎖）能出去。
- **謎題鏈**：
  1. **雙向密碼**：2030 剪報說保險箱密碼是「老闆第一台相機的型號數字」，1990 架上的老相機刻著 PX-1968 → 1968。
  2. **保存環境三選一**：1990 拿到舊底片，要決定放哪裡——窗台（被太陽曬融）、抽屜（發霉）、防潮箱（要插電才有用）。
  3. **翻拍**：2030 打開防潮箱，用手機翻拍底片 → 照片裡 1975 年的暗房門上寫著「暗房密碼 5203」。
  4. 2030 在暗房門輸入 5203 → 逃出。

## 地圖六：港邊老倉庫（✅ 試玩版已做）

- **主題**：1990 港邊倉庫，工人正在補水泥地；2030 廢棄倉庫，只有捲門能出去。
- **新玩法**：
  - **位置被打亂、要做記號**：4 個一模一樣的木箱，1990 箱子開著、看得到內容；2030 的箱子被後來的人搬亂（每局隨機），全都釘死。1990 說「左邊第幾箱」沒用，要用**紅油漆**在裝鐵鎚的箱子上做記號。2030 撬錯箱子會多一道時間裂痕。
  - **埋進水泥**：捲門的銅搖把掛在牆上會被偷。1990 把它按進還沒乾的水泥格 → 2030 用鐵鎚敲開水泥拿到。（1990 晚一步才埋也行，碎水泥裡會露出來）
  - **上油防鏽**：海風會讓鏈條鏽死。1990 用機油給捲門鏈條上油 → 2030 才搖得動。
- **謎題鏈**：1990 找鐵鎚 → 做記號 → 埋搖把 → 上油；2030 撬記號箱拿鐵鎚 → 敲水泥拿搖把 → 搖開捲門。

## 章節規劃（2026-11-18 起）

使用者希望每一關有不同的解謎，不一定都是「兩個年代」。改成**章節制**：同一章 3～6 關共用一個主題和核心機關，下一章換一種完全不同的密室。

| 章節 | 兩邊 | 核心玩法 | 狀態 |
|---|---|---|---|
| 第一章・隔代房間 | 1990 × 2030 | 過去的行動改變未來 | ✅ 6 關 |
| 第二章・深海研究站 | 控制室 × 機房 | 一邊看資訊指揮、一邊動手（資訊完全不對稱）、每局隨機 | 🚧 第 7 關 |
| 第三章・鏡中宅邸（構想） | 現實 × 鏡中 | 左右相反：鏡中的東西位置、文字都是反的，一邊動另一邊跟著鏡像 | 構想 |
| 第四章・夜班博物館（構想） | 監視室 × 展場 | 一人看監視器、一人在黑暗展場拿手電筒；躲巡邏、解展品謎 | 構想 |
| 第五章・夜行列車（構想） | 前車廂 × 後車廂 | 列車在動：切軌道、對時刻表、車廂分離倒數 | 構想 |

## 第二章：深海研究站

### 第七關・緊急撤離（✅ 試玩版已做）

- **兩邊**：控制室（三個螢幕＋三個按鈕，看得到所有資訊）／機房（保險絲盒、五個閥門、逃生艙門，看不到螢幕）。
- **謎題鏈（每局隨機）**：
  1. **電力**：控制室螢幕寫著保險絲顏色順序 → 機房從架上拿保險絲、照順序插進四格 → 控制室拉電源桿。順序錯 = 短路，警報 +1。
  2. **閥門**：控制室螢幕寫著要開哪些符號（△○□☆◇）的閥門 → 機房轉開、其他關上 → 控制室按加壓。錯 = 管子爆開，警報 +1。
  3. **艙門密碼**：控制室螢幕給一串符號；機房每個閥門底座刻著數字 → 換成數字，機房輸入進艙。
  4. 控制室按「釋放逃生艙」→ 逃出。
- 「時間裂痕」在這章叫「警報」。不同房間不顯示對方的殘影。

## 輔助功能與難度

- **提示**：按 H 或左下角按鈕。提示會依照「目前進度」告訴你下一步。多人時全隊共用次數，大家都會看到。
- **難度**：
  - 簡單：提示 5 次、時間裂痕上限 5、拉桿 5 秒內
  - 普通：提示 3 次、時間裂痕上限 3、拉桿 3 秒內
  - 困難：提示 1 次、時間裂痕上限 2、拉桿 2 秒內，右上角線索欄只剩一句
  - 單機時拉桿再多給 5 秒（要按 Tab 切換）。
- **章節**：過了前一關才解鎖下一關；每關記錄三種難度各自的最快時間（存在這台電腦的瀏覽器）。有「全部解鎖（試玩用）」。
- **捏角色**：衣服、膚色、髮型、髮色、褲子、配件。同年代的隊友看到實體，不同年代看到半透明的「時間殘影」，頭上有名字；走路會擺手擺腳。單機時看得到另一個年代的自己停在哪。

## 防卡關與防作弊（v0.4 修正）

- 有人斷線時，手上的東西會交給同年代的隊友；沒人可以接的話，1990 的東西會被時間修正放回原位。
- 遊戲開始後不能換年代。
- 遊戲結束後不再接受動作和密碼輸入。

## 試玩版說明

- 檔案：`隔代房間_試玩版.html`，點兩下用瀏覽器開（需要網路載入 3D 引擎）。
- 現在有 7 關（兩章），可以單機或多人連線。
- 單機版：一個人用 **Tab 切換 1990 / 2030**，自己扮演兩邊，先驗證謎題好不好玩。
- 之後的多人版：每個人固定在一個年代，靠語音溝通。
